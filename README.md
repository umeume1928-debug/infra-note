# インフラノート（ITインフラ学習Webアプリ）

ITインフラの用語をメモして、クイズと間隔反復で覚えるための学習アプリです（PWA対応。iPhoneのホーム画面に追加できます）。

## 機能
- **初期用語 156語**（11分野：ネットワーク基礎、IPアドレス・サブネット、ルーティング、プロトコル、DNS・Web、セキュリティ、Linux、クラウド、運用、ストレージなど）。基本情報・CCNA・LPIC・AWS のタグ付き
- **いろいろな出題形式**：4択（用語→説明／説明→用語）、○×、記述（用語を入力）、手書きの問題。**自分で追加した用語も自動で出題**
- **間隔反復**：正解するほど復習の間隔が延び（1日→3日→1週間…）、間違えた用語はすぐにまた出題される。1日に覚える新しい用語の数は設定で変えられる
- **フラッシュカード**：思い出せた度合いを4段階で自己評価
- **ポート番号ドリル／サブネット計算ドリル**（サブネット問題は毎回ランダムに作られ、解き方の解説付き）
- **図解**：OSI参照モデル、3ウェイハンドシェイク、DNSの名前解決、NAPT、ロードバランサー
- **進捗**：直近14日の学習量のグラフ、習得度、分野ごとの定着度、間違えやすい用語、連続学習日数
- 分野・資格・お気に入りで絞り込んで出題、検索、関連用語へのリンク
- ダークモード（自動／ライト／ダーク）、バックアップの書き出し・読み込み、オフラインでの動作、更新の通知

## ファイル構成
| ファイル | 内容 |
|---|---|
| `index.html` | 画面の骨組み |
| `style.css` | デザイン（ライト／ダーク） |
| `data.js` | 初期用語・ポート番号のデータ（**用語を増やすならここに追加**） |
| `diagrams.js` | 図解（SVG） |
| `app.js` | アプリの処理 |
| `sw.js` | オフライン対応（Service Worker） |

## 以前のバージョンからのデータ引き継ぎ
初めて開いたときに、旧バージョンのデータ（自作用語、進捗、正解数、学習日）を自動で新しい形式に変換します。旧データは消さずに残します。旧バージョンで書き出したバックアップファイルも読み込めます。

## GitHub Pagesで公開する
1. このリポジトリの Settings → Pages → Build and deployment で「Deploy from a branch」を選ぶ
2. Branch を `main`、フォルダを `/(root)` にして Save
3. 表示された `https://ユーザー名.github.io/infra-note/` を iPhone の Safari で開く
4. 共有ボタン →「ホーム画面に追加」

## アプリを更新するとき
ファイルを変更したら、`sw.js` の `CACHE` の番号（例：`infra-note-v2.0.0`）を上げてください。次にアプリを開いたとき「新しいバージョンがあります」と表示されます。

## 注意
- データは端末のブラウザ内に保存されます。別の端末との自動同期はありません。
- Safari のWebサイトデータを消すと記録が消えることがあります。設定画面から定期的にバックアップを書き出してください。
